# Network Labs

A collection of hands-on networking labs, documenting my progress as a network engineering student. Each lab includes a topology diagram, device configurations, and a written explanation of what was configured and verified.

## Tools Used
- Cisco Modeling Labs (CML)
- Cisco Packet Tracer (where applicable)

## Labs

| # | Lab | Description |
|---|-----|-------------|
| 01 | [Basic Inter-Subnet Connectivity](./01-basic-inter-subnet-connectivity) | Router connects two switches/PCs on separate subnets. Configured static IP addressing and verified connectivity across subnets using the router as default gateway. |
| 02 | [External Connector (NAT Mode)](./02-external-connector-nat-mode) | Added an External Connector in NAT mode to provide outbound internet access to internal lab devices, with automatic DHCP, NAT, and DNS. |

More labs will be added as I progress through networking and cybersecurity coursework.
